
# Customer Data Quality Analysis Using Microsoft Excel

## Project Overview
This project focuses on customer data management and basic data analysis using Microsoft Excel. It demonstrates how Excel formulas and data visualization can help organize customer records, identify data quality issues, and summarize information.

## Objectives
- Organize and manage customer records.
- Identify missing information and duplicate records.
- Practise Excel formulas for data analysis.
- Summarize customer information using a dashboard.
- Improve data accuracy and reporting skills.

## Tools Used
- Microsoft Excel

## Workbook Sheets
- **Customer Records:** Customer details, record organization, and data quality checks.
- **Dashboard:** Summary metrics and a customer status overview.
- **Formula Practice:** Examples of Excel formulas and their results.

## Excel Functions Practised
- `SUM` — Calculates the total of numeric values.
- `SUMIF` — Adds values that meet a specific condition.
- `AVERAGE` — Calculates the average value.
- `MAX` and `MIN` — Find the highest and lowest values.
- `COUNTIF` — Counts cells that meet a condition.
- `VLOOKUP` and `XLOOKUP` — Retrieve information from a data table.
- `IF` and `IFERROR` — Apply logical conditions and handle formula errors.
- `TRIM` — Removes unnecessary spaces from text.

## Data Quality Techniques
- Identifying duplicate records.
- Checking for missing phone numbers.
- Organizing customer information.
- Using conditional formatting to highlight data.
- Applying sorting and filtering.

## Key Learning Outcomes
- Spreadsheet data organization and formatting.
- Formula-based calculations and lookups.
- Basic customer data quality checks.
- Creating a dashboard for summary reporting.
